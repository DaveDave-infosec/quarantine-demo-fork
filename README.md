# quarantine-demo-fork

Demo fixture for Quarantine, a consensus-driven dependency containment dApp on GenLayer.

This repo is a community-style fork of `payout_skill` from quarantine-demo-skills, rewritten in a different style.

Its commits are deliberately divergent from every upstream release, so no byte-for-byte match exists. Quarantine has to read the code itself to decide whether the fork is exposed.

Do not use this skill in any real deployment.
